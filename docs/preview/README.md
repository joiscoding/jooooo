# Preview assets

Generated with `npm run build && npm run capture` (Playwright).

- `01-home.png` — gallery wall + filters  
- `02-look-detail.png` — look detail + add to album  
- `03-albums.png` — albums list  
- **`demo-walkthrough.webm`** — full **demo tour** (~1–2 min, silent): home → scroll gallery → filter → open a look → create album & save look → add a link → albums list → reopen album → home.  

Running `npm run capture` also writes `preview.webm` to `capture-output/` only (same bytes as the demo file).

Regenerate anytime after local changes.
